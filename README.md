# RIMBA | Beyond the Trail

Website brand RIMBA, perlengkapan outdoor untuk jalur tropis Indonesia.
Dibuat untuk tugas mata kuliah **Strategy Brand Communication**, Program Studi Ilmu Komunikasi, Universitas Dian Nusantara (UNDIRA).

> RIMBA adalah brand fiktif. Produk, harga, dan spesifikasi di website ini hanya contoh.

## Isi halaman

- Hero kampanye "Jelajah untuk yang Tangguh!"
- Koleksi 4 produk: Sepatu XPDIC 2, Jaket Kabut, Carrier Lembah 45L, Tenda Ranu 2P
- Sorotan produk unggulan XPDIC 2 dengan pilihan ukuran
- Cerita brand: makna nama, logo, dan tagline
- 5 karakter brand: Tangguh, Eksploratif, Natural, Modern, Fungsional
- Poster kampanye
- Form langganan "Kabar Jalur" (tampilan saja, belum terhubung ke server)

## Menjalankan di komputer sendiri

Cukup buka `index.html` di browser. Tidak perlu install apa pun.

## Deploy ke Vercel

1. Push folder ini ke repository GitHub.
2. Buka vercel.com, pilih **Add New > Project**, lalu import repository tersebut.
3. Framework Preset pilih **Other**. Build Command dan Output Directory dikosongkan.
4. Klik **Deploy**.
